### 🎭 Elementos Visuais Novos

#### Bolhas Decorativas (Hero):
```scss
- 5 bolhas em tamanhos variados
- Animação: 20s infinite
- Backdrop filter: blur(5px)
- Opacidade: 0.1
- Movimento: translate + scale
```

#### Ondas SVG (Products):
```html
- SVG wave no topo
- Altura: 60px
- Cor: branco (#ffffff)
- Efeito de transição suave
```

#### Tipografia Gradient (Hero Title):
```scss
- Font-size: 4rem (desktop)
- Font-weight: 900
- Gradient: white → warm white
- Text-shadow: 3px 3px 6px
```
